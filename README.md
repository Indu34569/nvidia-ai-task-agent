# NVIDIA AI Task Agent

A beginner-friendly AI task assistant built with Python and the NVIDIA API.

## What it does

The agent accepts natural-language tasks and uses an AI model to generate helpful responses.

It also provides:

- Task history tracking
- Interactive command-line interface
- NVIDIA AI model integration
- Python-based implementation
- Persistent task history
- Simple workflow for learning and experimentation

## Tech Stack

- Python
- NVIDIA API
- OpenAI Python SDK
- Git
- Command-line interface

## Model

The project currently uses:

`openai/gpt-oss-20b`

through the NVIDIA API.
